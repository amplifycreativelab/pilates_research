# Pilates supplier research

A mobile-friendly comparison of 45 Alibaba supplier listings: 15 each for Pilates/yoga mats, small Pilates balls and grip socks.

## Open the page

Download `index.html` and open it in a browser. It is a standalone file with no dependencies or build step. Alibaba links need internet access.

- Search supplier information and filter by product.
- Sort by category rank or supplier name.
- Expand specifications, customization, scale, freight and assessment.
- Save suppliers in your browser and filter to your saved list.
- Click a supplier name to open its Alibaba listing in a new tab.
- Browse on mobile without horizontal scrolling.

Saved entries stay in the same browser/device and are not synced.

## Research notes

Research date: 15 September 2026. Prices are AUD. Shipping observations use Australia, postcode 2000, sometimes with a capped A$30 promotion. Obtain current quotes to your actual address. Stock and custom minimums differ. Rankings compare screened listings; supplier claims and quality require sample validation. Full interpretation notes are included in the page.

## Edit with Codespaces

Open this repository in a Codespace and edit `index.html`. For a local preview:

```sh
python3 -m http.server 8000
```

Open port 8000 from the Ports panel. No dependency installation is needed.

## Optional GitHub Pages

The root `index.html` is ready for static hosting. If Pages is available for this repository/account, configure Settings → Pages → Deploy from a branch → main → / (root). Review site visibility before enabling it. This upload does not enable Pages.
